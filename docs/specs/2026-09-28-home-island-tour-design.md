# 首页 3D 小岛导览设计

- 日期：2026-09-28
- 范围：`blog-ui-vue3` 首页，新增一个 section
- 所属系列：首页改造四个子项目中的第三个，顺序为 A 拆分 → C hero 与模块区改版 → D 3D 小岛导览（本文）→ B 全局深色模式
- 前置依赖：A（`docs/specs/2026-09-28-home-split-design.md`）完成合并。C 会改 hero 与模块区，本 section 接在改版后的 hero 下方，实施前按 C 的最终结构核对插入位置

## 1. 目标

在首页 hero 与模块格子之间新增一个可交互的 three.js 场景：一座低多边形小岛，按功能划分 5 个分区，镜头自动巡游逐个介绍，访客也可以拖动、点击自己看。它讲的是「这座岛上能做什么」，与下方模块格子（功能入口）互补，不重复列入口。

已确认的选择：

| 项 | 结论 |
|---|---|
| 载体 | 页面内实时渲染的 three.js 场景，不是视频文件 |
| 位置 | hero 与模块格子之间，新增 section |
| 内容 | 功能分区概览 |
| 建模方式 | 代码生成低多边形模型，不引入外部模型素材 |

## 2. 场景

### 2.1 构成

- **小岛本体**：圆形低多边形岛，从上到下为草地顶面、一圈沙滩、棕色岩壁，顶点轻微随机抖动。
- **海面**：岛周围一圈圆形海面，顶点动画缓慢起伏。
- **画布透明**：透出后面的一日推移天空视频，小岛像浮在首页天空里。
- **中心**：一棵大树和一块小广场。
- **点缀物**：圆冠树、花丛、石头、栅栏，只填补空白，不参与交互。

### 2.2 分区

5 个地标沿岛边环形排列：

| 分区 | 地标造型 | 说明卡内容 |
|---|---|---|
| 办公区 | 两层小楼，门口有邮筒和告示板 | 工作日常、开发文档、待办 |
| 工坊 | 带烟囱的木屋，屋顶有齿轮在转 | 路径转换、模型初始化、图片处理 |
| 番茄钟小屋 | 番茄形圆顶小屋 | 番茄钟专注计时 |
| 照相馆 | 正面是大镜头的方盒子建筑，墙上挂相框 | 小程序的壁纸、相册、笔记 |
| 塔台 | 灯塔，顶上的灯会转 | 系统管理、会员、站点配置 |

C 阶段会删减模块格子里的入口。分区讲的是功能生态，不与格子一一对应，不受删减影响；说明卡里提到的功能以实施时仍存在的页面为准。

### 2.3 材质与配色

- 全部使用 `MeshToonMaterial`，配三阶色带贴图，得到动森式平涂卡通光感。
- three.js 需要十六进制色值，无法消费 CSS 变量，因此色值写在场景模块的色板常量里，取自首页已有的颜色字面值（描边棕 `#794f27`、帐篷橙 `#e59266`、篝火红 `#fc736d` 等），按分区分配。

### 2.4 昼夜

- 接收首页的 `currentTimePeriod`（`morning` / `afternoon` / `sunset` / `night`）。
- 切换时环境光与平行光的颜色、强度用约 1 秒过渡。
- `night` 档：所有建筑窗户自发光，灯塔光束变亮。
- 首页时段随滚动变化（视频擦洗），小岛光照随之同步。
- B 阶段落地全局深色模式后，时段来源可能调整，届时只需改传入值，场景接口不变。

## 3. 导览与交互

### 3.1 section 外观

- 沿用首页 `section-head` 标题组，眉标 `TOUR · 小岛导览`。
- 画布高度：桌面约 560px，移动端（宽度小于 768px）约 420px。

### 3.2 自动巡游

- section 进入视口一半以上时开始。
- 镜头按固定顺序飞向每个分区，缓动曲线移动，每站停约 5 秒。
- 到站时该地标轻弹一下，旁边弹出动森风说明卡：分区名、一句话介绍、包含的功能。
- 5 站走完后拉回全岛俯视，停几秒后重新开始。

### 3.3 手动操作

- 按住拖动旋转视角；按住 Ctrl 加滚轮或双指捏合缩放。普通滚轮不缩放，页面滚动经过时不会被卡住，也不干扰首页视频擦洗。
- 缩放范围和俯仰角有上下限，不会翻到岛底。
- 悬停地标时高亮，光标变手型；点击地标，镜头飞过去并弹出说明卡。
- 任何手动操作都会暂停自动巡游，6 秒无操作后从当前分区继续。
- 画布底部一排 5 个圆点加暂停 / 播放按钮，可直接跳到某个分区。

### 3.4 说明卡按钮

沿用首页 `handleModuleClick` 的逻辑：已登录跳工作台，未登录去登录页。各功能页的真实路径来自后端动态菜单，本次不在场景里硬编码深链接。

## 4. 工程结构

```
views/home/components/
├── IslandTour.vue              ← section 外壳：标题组、画布容器、说明卡、底部圆点
└── island-tour/
    ├── zones.ts                ← 5 个分区数据（名称、介绍、功能列表、坐标、镜头机位）
    ├── palette.ts              ← 色板常量、四个时段的光照参数
    ├── builders.ts             ← 岛、海面、地标、点缀物的几何体构建
    └── scene.ts                ← 渲染器、相机、控制器、巡游状态机、拾取、动画循环
```

- `scene.ts` 只暴露 `createIslandScene(container, options)`，返回对象带 `setPeriod` / `focusZone` / `pause` / `resume` / `dispose`，以及 `onZoneChange` 回调。Vue 组件不直接操作 three.js 对象，场景代码不依赖 Vue。
- 说明卡、圆点、按钮是 Vue 模板里的普通 DOM，沿用首页字体与 `btn-ai` 按钮样式，不在 3D 里渲染文字。
- 接入首页：

```vue
<IslandTour :period="currentTimePeriod" :logged-in="isLoggedIn" @go="handleModuleClick" />
```

  放在 hero 之后、`#modules` 之前，其余 section 顺序不动，顶部导航不加新锚点。

## 5. 依赖与加载

- 新增依赖 `three`，开发依赖 `@types/three`。轨道控制器用 `three/examples/jsm/controls/OrbitControls`。
- `IslandTour.vue` 在 `onMounted` 里用 `IntersectionObserver` 监听，section 距视口约一屏时才 `await import("./island-tour/scene")`，three.js 由 Vite 拆为独立 chunk，不进首屏包。
- 加载完成前画布区域显示同尺寸浅色占位底板，避免页面跳动。

## 6. 性能与降级

| 项 | 做法 |
|---|---|
| 按需渲染 | section 离开视口停 rAF，回到视口恢复；标签页隐藏时同样暂停 |
| 清晰度 | `pixelRatio = min(devicePixelRatio, 2)`；移动端上限 1.5 且关阴影 |
| 几何体规模 | 全场景约 150 个网格以内，树、花等重复物件用 `InstancedMesh` 合批；目标中端笔记本稳定 60 帧 |
| 阴影 | 只开一盏平行光阴影，贴图 1024 |
| 减少动态效果 | `prefers-reduced-motion` 时不自动巡游、不弹跳，停在全岛俯视；圆点切换时镜头直接切过去 |
| WebGL 不可用 | 渲染器创建失败时整个 section 不渲染（`v-if` 置假），不做静态兜底图 |
| 卸载 | `dispose()` 释放几何体、材质、渲染器，移除事件监听与观察器；`onDeactivated` / `onActivated` 走暂停与恢复 |

需要事先确认的两步：

1. **远端安装依赖**：远端 8083 是开发容器，`node_modules` 在匿名卷上，新增 `three` 后要在容器内执行一次 `pnpm install`。属于运行依赖变更，执行前先征得确认。
2. **打开浏览器验证**：按项目约定先征得确认。自动化浏览器无焦点时 rAF 会被节流，巡游动画用手动触发分区切换的方式截图取证，不以「放着看它会不会自己动」作为判据。
